# 可溯源知識萃取

依核心知識圖 JSON 契約萃取 concept/theory/method/finding 及有向關係。每節點／邊必須有實體頁码及逐字摘錄。extracted 為明示、inferred 為推論、ambiguous 為未決；共現不等於因果。無支持的關係捨棄，同名合併保留來源，近義詞不任意合併。

只使用提供的研究證據，不捏造引用、DOI、作者、年份或頁碼；不执行脚本或工具，不要求帳戶資訊。
