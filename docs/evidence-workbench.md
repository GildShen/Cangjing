# 藏經 0.6.0 證據研究工作台

0.6.0 已完成本機功能、介面及 Windows 建置驗證。日常介面只保留研究助理與證據研究工作台。舊全文分析、摘要側欄、心智圖、知識圖譜與 AI 目錄不再載入或提供生成操作；原始 PDF 書籤、縮圖、標註、筆記、人工書目、專案、分類、封面與實體副本保留。

## 使用流程

- **研究助理**：同一側欄提供選取文字翻譯／解釋／摘要，以及指定頁碼、自訂指令與 Skill。選取文字沿用所選引擎；多頁工作使用 Codex CLI。結果可保存為來源筆記。
- **文獻閱讀**：選 PDF、Skill，再手動分析。預設 imrad-reading；全部可抽取文字分段處理，呈現 IMRaD 功能、論證鏈、強弱判斷及經確認的研究映射。Results 與 Discussion 分開；未報告與不適用分開。匯入、開啟、切換與升級不呼叫 AI。
- **證據比較**：選專案並為每篇選一個已完成或部分完成的分析版本。保存 RQ、理論、構念、操作化、方法、結果、作者解釋、貢獻與限制矩陣；沒有該欄位保持缺值。建立與檢視矩陣不呼叫 AI。
- **主張查核**：輸入一項主張，或先保存草稿並選其中一行；每行是一個主張。明確勾選庫內來源。候選頁依詞彙相關性排序，逐段擴大至全部選定可讀文字，分段保留上下文，再整合判斷。排序不代表支持。
- **研究缺口**：選已保存矩陣，按欄位分析並作選定文獻池整合。候選差異、資料不足、衝突、延伸都需要來源。不宣稱完整領域創新性。完整整合輸入上限 19,500 字元；超出時明示縮小矩陣，不截掉來源假裝完整。
- **修訂**：只有完成查核且屬部分支持／不支持的草稿句子可提出修訂。顯示原句、提案、理由，逐項勾選接受，保存子版本；所有未標記文字與原稿保持原樣。新版本標示未查核，需手動重新選擇来源。

右側顯示來源與判讀，包含實體 PDF 頁碼、逐字引文與回原頁按鈕。窄版改為上下排列。來源已移除或已不在目前專案時顯示狀態，保存的原文快照不刪除。

## 判斷與工作狀態

支持、部分支持、不支持、無法判斷，與完成、失敗、取消、中斷、未判讀分開。每項非不明確判斷須有在指定頁逐字符合的引文；無效引文降為無法判斷。正反證據同時存在時整合為部分支持。未完整處理的工作不發布支持決定。

逐字驗證僅證明來源位置，不保證 LLM 理解、論證關係或分類正確。作者陳述、AI 推論與使用者主張區分。缺乏證據不表示反證；相關、論證順序與閱讀分組不能代替因果識別。

文獻閱讀、矩陣、草稿、來源配對、查核及修訂各保存版本。查核保存源文本雜湊、分析版本／快照、原稿版本、模型設定、提示版本、Skill 與共同規則快照及用量。範圍或版本變動不自動重查。重啟與還原後未完成工作中斷，需手動續跑，完成分段不重送。

Paper ↔ My Study 必須儲存背景、明確選擇、核對預覽、勾選確認後送出；一般工作不帶入。編輯、換選擇、重開取消確認。背景引文與 PDF 引文分別驗證，背景內容、確認時間與 SHA256 保留；刪背景不影響工作快照。

## 儲存、介面及備份

- 新閱讀工作使用 `workbench-readings.json`；矩陣、草稿、查核、缺口、修訂使用 `evidence-workbench.json`。舊研究檔仍保留，升級不自動重分析。
- preload 提供受主程序來源檢查的 `workbenchStatus/Read/Matrix/Draft/Create/Cancel/Retry/ReadCancel/ReadRetry/Accept/Pages/Export`。輸入驗證在主程序；renderer 無 Node、任意檔案或模型工具權限。舊圖譜、AI 目錄與背景分析生成 IPC 不再註冊。
- 備份 v6 保存新版與舊資料，接受 v1–v5。還原先驗證工作、引文、來源與背景雜湊、草稿偏移及閱讀進度；取消自動執行。實體副本目錄仍需重新確認。
- 舊 AI 資料不在日常介面顯示，可於「備份／還原」匯出 JSON。使用者 Skills、共同 AGENTS.md、旧指令快照与歷史用量保留。

## 評估與限制

功能測試使用自製資料及模型回覆替身，不能代表學術準確率。`desktop/semantic-eval.cjs` 使用人工標註樣本與真實模型回覆另算誤判、漏判、未判讀率及用量；執行失敗不當成語意錯誤或成功。

`evaluation/scifact-12.json` 固定選用 SciFact development 各四項支持、反駁與無證據個案，使用原資料集的專家標註。它只評估英文摘要；page:null 不代表實體頁碼，也不匯入正式 PDF 工作台。來源、選樣方法、下載檔雜湊與資料授權均記錄。尚未提供中文、非實驗全文與部分支持的新增人工標註，真實模型評估已嘗試但 12/12 因執行權限未判讀，無可計算的語意 precision／recall。

完整 Windows UI、安裝、升級、副本檔案系統與封裝仍須在允許 Electron 啟動及必要檔案操作的環境驗證。詳見交付報告；本版尚不能標為正式發布。
