- `npm run test:ui`：41 項真實 Electron／Chromium 檢查通過。使用自製文字 PDF、EPUB 與獨立測試 profile，沒有私人文件、真實金鑰或 AI 服務請求。

- NSIS x64 安裝檔及可執行資料夾成功建置。獨立 appId、執行檔、資料路徑、資料庫與設定鍵已檢查；MIT／第三方授權包含於打包內容。

Electron 44.3.0 執行資源已從官方發行下載並以 npm 套件提供的 SHA-256 清單核對：`26bf9a617d58d81772b3d68305d59ee48272969c15083c06db634a77358a8d9d`。最終測試與安裝檔使用藏經獨立安裝的 runtime；不依賴藏書目錄，也未複製來源 node_modules 或安裝包。來源程式仍保持未修改。

## 實際限制

- 真實 Codex／OpenAI 服務回覆、額度與模型權限未做端到端請求測試。CLI 版本須支援本專案使用的隔離選項；JSON 不合規則會標為失敗，可重試並保留已完成分段。
- 掃描 PDF 可閱讀與顯示首頁縮圖，沒有 OCR。全文分析只覆蓋可抽取文字，無文字頁明列為部分完成。可核對摘錄並不能保證模型論述正確。
- 安裝檔未簽章；本次驗證建置產物，未在另一台乾淨 Windows 實際安裝／解除安裝。沒有測試 macOS／Linux。
- npm audit 回報開發建置工具鏈 9 項（8 high、1 moderate），主要涉及 electron-builder 的下載／快取相依套件。未使用強制降版或破壞性升版處理，不宣稱完整供應鏈安全稽核通過。打包沒有應用 runtime npm 生產相依套件，但這不等於 Electron／vendor 自動無風險。
- ZIP 備份上限 1 GB，採記憶體編解碼；未做大型庫、磁碟耗盡與不同版本備份壓力測試。使用還原前應先建立備份。還原不包含外掛程式與金鑰，會停用自動分析。
- v1 外掛是 sandboxed renderer，沒有全文／AI／網路／寫核心筆記能力；命令結果最多 20,000 字，超限報錯，可改用核心筆記匯出。未宣稱可抵抗惡意資源耗盡。
- 跨文件全文搜尋、BibTeX／RIS 引用、印刷頁碼對照與更多外掛擴充點尚未實作。

測試截圖、profile、依賴、安裝包與使用者資料均在 Git 提交範圍之外。
