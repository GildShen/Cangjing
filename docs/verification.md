# 0.2.1 驗證與限制

驗證日期：2026-10-03（Asia/Taipei）。Windows 11、Node.js 24.13.0、npm 11.6.2、Electron 44.3.0。

## 已驗證

- 單元測試 34 項通過；Electron／Chromium 介面檢查 84 項通過，renderer console error 為 0。自製三頁 PDF、第二份合成 PDF 與合成舊版資料，使用全新獨立測試 profile；沒有私人文件、真實金鑰或雲端 AI 請求。
- 真實分頁角色、44px 目標、方向鍵／Home／End、空專案引導、分頁範圍各自記憶與重載還原、切換不改組織資料。最近閱讀／全部文獻／分類、專案与分類交集、多專案關聯、改名／刪除保留文件。
- PDF 匯入、重複辨識、完整比例首頁縮圖、文字搜尋、頁碼筆記、掃描空白頁提示；不支援 EPUB 的匯入錯誤。合成舊 EPUB 保留於資料庫，從可閱讀列表及側欄數量排除；ZIP 編解碼與實際 IndexedDB 還原後原始位元組相同。
- 標註測試使用 Chromium DevTools Protocol 的可信滑鼠拖曳、真實右鍵、工具列實際點擊與鍵盤事件。三個選單項目、方向鍵／Enter／Escape、螢光筆／底線／註釋的來源與重畫、三個獨立圖示、選取保留、元素邊界 Range、換頁／換文件清除舊選取均通過。無選取與編輯欄位的可信右鍵事件沒有被 preventDefault。
- 用量合計不重複計入快取／推理、零與未回報分開、部分回報與 1 起算分段、可讀時間／模型、等待與正在分析區別。知識圖刷新後 details 開啟狀態與 summary 焦點保留。使用合成數值，不引用使用者畫面的數字或私人研究內容。
- 390×844、768×1024、1440×900、1920×1080、2560×1080 的文獻／專案分頁與 PDF 閱讀器均使用實際 viewport；無頁面水平溢出，窄版侧欄可收合。390／768／1440 的知識圖與展开用量亦擷取檢查；表格寬時內部橫向捲動。
- 背景／多頁／知識圖工作、完整 Unicode 分段、原指令／覆蓋／來源驗證、取消／重試／重啟、獨立同意、快取與無重送，以及外掛隔離／權限／命令／停用與備份恢復檢查持續通過。AI 僅為測試替身，產品未加入替代服務。
- NSIS x64 安裝檔建置成功；ASAR 270 項檔案／目錄。新用量、舊資料及標註模組、MIT 與第三方聲明逐位元核對；EPUB.js、converter.js、export.js、測試、工作資料與 node_modules 不在執行包。檔案關聯只剩 PDF。

原版程式對本次合成 PDF 的可信拖曳／右鍵亦曾顯示選單，因此不能宣稱重現了使用者原始文件的全部失敗情況。此次修正與新增驗證覆蓋元素邊界、pointerdown 選取保留、選單鍵盤啟動及生命週期；私人文件未用於測試。

## 限制

- 未做真實 Codex／OpenAI 端到端請求，未使用私人文件。CLI 必須支援所用隔離選項；不合規 JSON 會失敗並保留進度。
- 沒有 OCR；可閱讀掃描 PDF，但無文字層不能建立文字標註或分析其文字。來源可核對仍不保證 AI 論述／關係正確。
- 安裝包未簽章，未在乾淨 Windows 安裝／解除安裝，未驗證 macOS／Linux。來源藏書目錄未修改；依賴為藏經独立安裝，沒有複製來源 node_modules 或安裝包。
- 開發建置工具鏈的既有 npm audit 告警 9 項（8 high、1 moderate）仍未處理；未宣稱供應鏈稽核通過。
- 沒有大型 PDF 庫、複雜跨欄／特殊字體、磁碟耗盡或知識圖大規模效能壓力測試。ZIP 備份上限 1 GB 並在記憶體處理；還原前應先備份。舊資料、來源筆記與組織關聯保留，還原停用自動送出與知識萃取。
- EPUB 閱讀與轉換已停止支援；歷史原始碼保留於儲存庫，不載入產品。舊資料只能相容保存、備份或匯出原始檔。
- 跨文件全文搜尋、BibTeX／RIS、Zotero、雲端同步與向量資料庫仍未實作。
