# 0.3.0 驗證與限制

驗證日期：2026-10-03（Asia/Taipei），Windows 11、Node.js 24.13.0、Electron 44.3.0。

## 已驗證

- 單元測試 52 項、Electron／Chromium 介面檢查 130 項通過；renderer error 為 0。全部使用合成 PDF、獨立測試 profile 與 AI 替身，沒有私人文件、真實金鑰或雲端 AI 請求。
- 四個內建 Skill 通過官方 skill-creator 的 UTF-8 validator。資料夾／ZIP 匯入、路徑穿越、符號連結、重複名稱、無效 UTF-8／YAML、檔案與膨脹大小限制均有驗證。匯入只有文字，不執行腳本；CLI 隔離選項保持。
- 共用 AGENTS.md、啟用／停用／刪除／恢復預設、工作建立時的完整指令快照、雜湊、保留進度重試、快取隔離、歷史與備份還原均通過。
- 預讀摘要與來源理解架構來自同次 AI 回應；顯示架構沒有額外 AI 呼叫。作者明示／分析推論分開，無效來源關係排除。額外知識萃取需明確操作，啟用與匯入不會自動建立萃取工作。
- 專案清單與單一編輯表單、數量、重名、儲存／取消、未儲存確認、失敗交易、刪除確認與多專案 PDF 關聯保留通過。
- PDF 封面使用可信縮圖右鍵及頁碼輸入，驗證頁碼界限、完整比例、重設第一頁、渲染／儲存失敗、重載與備份；PDF 原始位元組與閱讀位置未改。
- 保留 PDF 匯入、分頁鍵盤操作、搜尋、三種標註與可信文字選取／右鍵、可讀用量、外掛隔離、舊 EPUB 相容保存等既有檢查。
- 390／768／1440／1920／2560 寬度的文獻、閱讀器、專案管理與 Skill 管理均無水平溢出；390／768／1440 的封面與理解架構亦檢查。
- NSIS x64 安裝檔成功建置；ASAR 共 333 個檔案／目錄，28 個關鍵程式、Skill 與授權檔案與來源逐位元比對。正式依賴只有 js-yaml 與 argparse；封裝包含授權。排除測試、工作資料、金鑰、使用者 Skill 設定、EPUB／轉換模組。封裝內 SkillManager 可載入四個預設流程。

## 限制

- 沒有真實 Codex／OpenAI 端到端請求。原生檔案選擇器回傳使用測試替身；實際 Windows 選擇器操作未驗證。
- 安裝包未簽章，未在乾淨 Windows 安裝／解除安裝，未驗證 macOS／Linux 或實際封裝 Electron 啟動。原始藏書來源未由本次工作修改。
- 沒有 OCR。來源可核對仍不保證 AI 論述正確；跨文獻 Skill 只比較提供的內容，多頁選擇目前限同一 PDF。
- 既有 npm audit 告警 9 項（8 high、1 moderate）未處理。未做大型文件庫、特殊 PDF、磁碟耗盡與大圖效能壓力測試。
- 備份 ZIP 在記憶體處理，上限 1 GB。還原後自動分析與額外知識萃取停用；還原前應先備份。
- 跨文件全文搜尋、BibTeX／RIS、Zotero、雲端同步與向量資料庫尚未實作。
