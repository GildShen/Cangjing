# 藏經 0.5.0 IMRaD reading

`imrad-reading` 是新安裝的內建預設研究 Skill。從 0.4.0 升級時，舊內建預設 literature-evidence 改為 imrad-reading；已明確選擇的其他 Skill 或不套用選項保持。原四個內建 Skill、自訂 Skill、共同 AGENTS.md、舊分析、历史用量與工作快照保留。新增 Skill 不會重新排入已分析文件；只有明確按重新分析才產生新版本，舊版留在歷史。

## 三層閱讀

1. **IMRaD 理解摘要**：各部分解釋研究功能。Introduction 建立問題，Methods 說明證據取得與分析，Results 呈現結果，Discussion 解釋、對話理論與貢獻。Results 與 Discussion 是不同資料欄位與 UI 分支。理論、綜述、質性或歷史文章按實際內容辨識功能，未報告與不適用分開，不補造實驗、假設或操作化。
2. **研究邏輯**：Known → Gap → RQ → Theory/Hypothesis → Constructs → Operationalization → Method → Evidence → Claim → Contribution → Boundary/Limitations。各環節、相鄰支承與最強／最弱判讀附逐字原文及實體 PDF 頁碼；判讀標示 AI 推論。箭頭代表論證順序，不代表因果。分段階段不產生整篇強弱結論；全部文字抽取完成後再作整篇整合。
3. **Paper ↔ My Study**：文件分析詳情內填寫研究背景名稱與內容，儲存後由選單明確選擇，核對預覽並勾選確認，再按「以確認背景重新分析並映射」。背景不自動選取、不隨一般自動預讀帶入；編輯內容、換選擇或重新打開詳情會取消確認。尚未選擇及確認時明示缺資料，映射為空。映射引用需同時逐字符合 PDF 原文與確認背景，並說明移用限制。

## 工作與資料

全文预讀使用既有文字快取、分段排程、CLI、取消續跑與用量紀錄。新工作保存 Skill／共同規則指令快照與確認背景的完整內容、確認時間、SHA256。整篇 IMRaD 判讀有最後整合階段，可能增加一次 CLI 請求；開摘要或心智圖只讀結果，不送出 AI。背景不會變成 PDF 的來源證據，也不替使用者宣稱自己的研究結果。背景文字最多 3,000 字，JSON 編碼後最多 3,500 字；名稱最多 120 字。

沒有來源、引文不在所列頁碼、研究背景引文不在已確認文字、非相鄰論證跳接等項目不採用。程式驗證來源存在，無法保證 AI 解釋、段落歸屬與最強／最弱判斷正確，仍需人工核對。掃描頁不 OCR，只有可抽取文字時才處理；覆蓋不足顯示部分摘要。資料不足不推造研究內容。

摘要側欄與研究心智圖各呈現三層；心智圖層次線是閱讀分組，相鄰論證支承在來源節點內顯示，沒有因果邊。缺失與不適用保持標記。舊結果仍用舊欄位呈現，可手動重做。既有已完成結果的取消／繼續沿用快取；取消最後整合後再續跑只重做整合，不重送完成的抽取分段。

備份 v5 包含研究背景庫、三層結果、分段、已確認背景快照／雜湊、舊分析與指令快照；仍讀取 v1–v4。還原停用自動分析、保留舊背景確認作為原工作證據，新工作仍需重新選擇確認。刪除背景庫項目不移除已保存分析的快照。API 金鑰、Codex 登入與外部副本不封裝。舊兩代研究輸出契約持續驗證，不將新版指令偷套入舊工作。
