後續工作依資料可靠性與研究工作流排序：

1. **書目擴充**：作者結構化清單、文件類型、出版社、卷期、印刷頁碼與 URL。現有標題／作者／年份／期刊／DOI 人工欄位保留；原始 metadata、AI 候選、人工修訂來源與核對狀態分開。PDF 物理頁碼不等於印刷頁碼。
2. **研究問題與證據工作台**：現有專案筆記已可保存多文件證據；下一步把研究問題做成獨立實體，提供筆記排序、連結關係、失效來源整理及批次核對。不要複製文件來模擬關聯。
3. **跨文件全文搜尋**：為有文字層 PDF 建立本機分頁索引，提供關鍵字、專案、分類、標籤與狀態篩選，命中摘錄和原文跳轉。支援取消、增量重建與失敗提示；掃描頁不做 OCR。先評估 worker 與 IndexedDB，不預設向量資料庫。
4. **引用匯出**：在既有 Markdown 筆記以外加入 BibTeX／RIS。只以人工核對欄位輸出；缺失年份、作者、DOI 保持缺值，匯出前列出尚未核對資料。驗證特殊字元、多作者、中文書目與重新匯入。
5. **外掛 API 擴充**：先實作可審核、可測試的頁碼文字／選取事件與寫筆記 broker，再考慮分析器及更多面板。API 版本、權限與生命週期不可繞過核心文件資料模型。
6. **效能與資料演進**：將全文抽取與索引搬到 worker、測試大型庫、建立跨版本遷移／備份相容性與復原檢查。先處理資料可靠性，再加更多服務整合。

AI 資料必須能回查原文件的頁碼與短摘錄。系統會拒絕無法逐字比對的證據；書目欄位還需候選值出現在該摘錄中。這只驗證來源存在，不代表 AI 解讀正確，仍需人工確認。找不到來源時保留缺值，不捏造作者、年份、DOI、引用或頁碼。

不預設 OCR、雲端同步、Zotero、向量資料庫、外掛市集或原生任意程式碼。
