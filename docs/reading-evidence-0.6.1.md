# 0.6.1 閱讀與證據同步

PDF 為主要閱讀面，右側是目前頁面的来源證據；窄版使用可收合覆蓋側欄，保留閱讀位置。沿用閱讀色彩與同一圖示系統，不加入圖譜。

翻頁讀取既有分析，可選分析版本；點證據定位原文，固定可跨頁核對並返回原閱讀位置。段落定位只接受唯一文字層匹配；原引文先逐字比對文件頁面，斷行／空白只用於顯示位置匹配。重複段落明示位置未確認，不改寫證據。

段落連結綁定分析版本、欄位、頁碼、原文及判讀。來源筆記保存明確 evidenceRef；矩陣與查核反向引用使用已保存版本／來源配對，不以語意相似建立連結。原文可預覽後定位。複製連結可在同一應用工作階段使用，尚未提供外部瀏覽器或作業系統啟動的深連結。

閱讀工作區保存文件、實體頁碼、捲動、縮放、旋轉、分析版本與固定證據，存於本機 organization，隨 v6 備份保存。恢復為手動操作，不呼叫 AI；來源或版本移除時明示不可用。

本次不含通用 Markdown 編輯器、任意外掛、Bases、模板或全局多分頁工作區。只修改藏經。
