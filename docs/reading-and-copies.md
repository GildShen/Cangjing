# 藏經 0.4.0 閱讀與專案副本

PDF 工具列的「邊界翻頁」預設開啟。滾輪先捲動目前頁面；已到頁底再向下才到下一頁頂端，頁頂向上則到上一頁底端。同一波手勢最多翻一次，必須完成渲染並經過 240 ms 安靜期。第一／末頁不循環，水平、Shift、Ctrl 滾輪、對話框與閱讀區外操作不翻頁。渲染失败保留上一頁畫面。

「全文摘要」只呈現目前文件已有預讀資料，不觸發 AI。新結果包含概述、研究問題、理論／概念、方法、發現、結論與限制；每項可查看逐字來源並跳至實體 PDF 頁。缺值直接標示，不從無來源內容補寫。完整與部分覆蓋分開，列出文字頁／全文件頁數。舊結果標為零散結果，可從文件分析詳情手動重新分析；同規則重做也會保存舊版本。

左側保留「文件目錄」與「頁面縮圖」，原始書籤優先。「AI 目錄」需明確按生成並確認後才送出：快取全部可抽取文字、分段辨識標題、整合已核對來源，保存實體頁碼、短原文、候選層級與 Skill／共同規則快照。層級和分組一律標作 AI 推論。可取消、保留已完成分段重試、重做與回顧版本用量；重啟不自動送出未完成的目錄工作。掃描頁沒有 OCR，部分覆蓋明示。目錄沒有從未讀頁推造標題，無法核對的結果排除。

在研究專案管理中選擇 PDF 副本目錄。主程序原生選擇器會列出目錄、待複製數、同內容可重用數與檔名，確認後補齊已關聯文獻。沒有目錄時只建立邏輯關聯，介面會顯示。拖曳與關聯選單共用同一流程，複製失敗保留關聯與錯誤，可重試。每個專案有獨立副本，原始 PDF 與 IndexedDB 不變。

副本檔名取匯入原名（舊文獻退回標題）、安全字元與 SHA256 前 12 碼。實際檔名持久保存，標題改名不重命名副本。同名同雜湊可重用；不同內容選另一檔名，絕不覆蓋。更換目錄會重新確認與複製，舊目錄保留。移除關聯、刪專案或刪文獻不刪外部副本；刪專案會撤銷該專案未來的目錄寫入授權。這不是双向同步，沒有監看或跟隨手動修改外部檔案。

副本來源按 1 MB 傳送一次並由主程序以完整 SHA256 核對、快取供多專案重用。`project-copies.json` 另行保存專案目錄授權／目錄身分、文件雜湊、意圖、實際檔名與工作狀態；不把 IndexedDB 與檔案系統宣稱為同一原子交易。啟動恢復 pending／中斷發布工作；無來源等待 renderer 補送。寫入採獨佔暫存檔、雜湊驗證與不覆蓋發布，開啟目錄和複製均重新核驗已授權目錄身分，拒絕符號連結、Windows 重解析點及路徑逃逸。

備份版本 4 包含原 PDF、AI 目錄／歴史／用量／指令與副本記錄；不包含外部副本或主程序來源快取。舊版 1–3 可讀。還原所有副本目錄會撤銷授權，必須重新選擇並確認才寫入，已有外部檔案保留。正在研究或副本收尾時需先等待或停止工作。

限制：Node 路徑 API 的核驗無法提供對抗具備本機檔案修改權限攻擊者的原生目錄句柄級原子保證。複製前後均檢查 realpath、目錄 dev/ino 與重解析属性；仍不宣稱消除全部檔案系統競態。若磁碟不支援硬連結，使用獨佔複製發布；突然斷電可能留下未完成檔案，下次驗證不會採作成功副本，也不覆蓋它。更換目錄或異常中止可能保留暫存檔，程式不會跨變更後的授權目錄清理它。大量文獻與真實設備效能需另測。
